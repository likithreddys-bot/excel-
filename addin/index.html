    How to set up a local model (one time, about 10 minutes)
    1. Install Ollama from ollama.com/download (Windows, Mac or Linux).
    2. Open a terminal (Windows: Command Prompt) and download a model that can use tools: ollama pull qwen2.5:7b (about 5 GB; needs 16 GB RAM. With 8 GB RAM use qwen2.5:3b).
    3. Allow this page to talk to it, then restart Ollama. Windows: setx OLLAMA_ORIGINS "", then quit Ollama from the tray and open it again. Mac: launchctl setenv OLLAMA_ORIGINS "" and restart Ollama. Linux: set OLLAMA_ORIGINS= for the ollama service.
    4. Press Test below. If the browser asks to allow access to devices on your local network, choose Allow.

    A server on the company network works too: put its address above (for example http://10.0.0.5:11434). The page's security rule allows only this computer's addresses by default, so host the site inside the company for a network server.

    Privacy

    Strict (default): leave both boxes unticked. Only your question, column names, types, ranges and how empty each column is are sent. The AI then refers you to the result sheets instead of quoting numbers.

    Guardrails, always on: your files are read and calculated on this computer only and are never uploaded. Your rows, names, phone numbers, PAN, Aadhaar, e-mails, account numbers and ids are never sent: every request is checked before it leaves, and one that contains them is stopped. The page can talk to no server except Google's Gemini API and a local model on this computer. Nothing from your files is stored after you close the tab. See exactly what was sent with "What was sent to the AI".
    Local model: requests go only to the model server above, on this computer. Nothing leaves your computer and nothing is used to train anyone's model. With a local model it is safe to tick both privacy boxes, which gives better answers.
    Training: on Google's free tier, Google may use what is sent (your question and column facts) to improve its products. On a paid (billing-enabled) key, Google's terms say prompts are not used to train its models. For real customer files, use a paid key from your company's Google Cloud account.
